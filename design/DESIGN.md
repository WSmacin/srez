# Срез — UI Design v3

Обновлено: 2026-10-30  
Прототип: [`index.html`](index.html)

## Выводы по похожим приложениям

| Приложение | Что взять | Что не копировать |
|------------|-----------|-------------------|
| **YNAB** | Крупные суммы, спокойный белый фон, мягкие карточки ~12–16px, ясная иерархия «сколько свободно» | Нулевой бюджет на календарный месяц как единственная модель |
| **Monarch** | Много воздуха, список счетов с балансами, спокойные графики, «домашний» тон | Перегруз виджетами и банк-синк как must |
| **PiggyVest / копилки** | Дружелюбная типографика, отдельный блок сбережений | Детские иллюстрации |
| **Дзен-мани / Т-Банк** | «Свободные деньги», счета и копилка как сущности, понятный русский язык | Сырой учёт без периодов ЗП |

**Итог для Среза:** мягкий finance UI (как Monarch/YNAB), но ядро — период между зарплатами + семья. Меньше острых углов и «плакатного» шрифта; больше скруглений и спокойного гротеска.

## Визуальная модель v3

| Токен | Значение | Роль |
|-------|----------|------|
| `--bg` | `#EEF1F4` | фон |
| `--card` | `#FFFFFF` | карточки |
| `--ink` | `#1C2430` | текст |
| `--mute` | `#6B7785` | вторичный |
| `--line` | `#E2E7EE` | границы |
| `--teal` | `#0F766E` | бренд / плюс / CTA |
| `--teal-soft` | `#E6F4F2` | фон акцентов |
| `--amber` | `#C2410C` | обязательные / кредит |
| `--amber-soft` | `#FFF1E8` | подсказки |
| `--sky` | `#0369A1` | копилка / вклад |
| `--sky-soft` | `#E8F4FC` | фон копилки |

**Шрифт:** только **Manrope** (мягкие терминалы, нормальная кириллица).  
Не Unbounded (слишком рубленый) и не Inter как «лицо» бренда.

**Формы:** радиус карточек 18px, кнопок 14px, аватаров круг. Без зубцов, ромбов и «кассовой ленты». Легкая тень `0 8px 24px rgba(28,36,48,.06)`.

## Экраны

1. **Вход / Регистрация** — почта или ник + пароль; вход в семью позже  
2. **Сейчас** — можно тратить, свод, счета (на руках / копилка), ближайшее  
3. **Счета** — остаток наличных/карты (не только ЗП), копилка, вклады  
4. **План** — доходы, платежи, копилки к сроку  
5. **Долг** — остаток, **ставка %**, пересчет срока и переплаты  
6. **Копилка / вклад** — баланс, **ставка %**, прогноз дохода  
7. **Лента / Итоги / Семья** — как раньше (ник или ссылка)

## Расчеты (логика UI)

- **Кредит:** аннуитет или упрощенно по мин. платежу; показ «закрытие к …», «переплата ≈ …» при смене ставки/платежа  
- **Вклад / копилка:** простой или капитализация раз в месяц; «через год ≈ …»  
- **Сейчас на руках** входит в «Всего в периоде», копилка **не** тратится в «можно тратить» (отдельно), пока пользователь не переведет

## Модель ИИ для продолжения работы

Для сборки продукта (логика процентов + UI + sync): **Claude Opus 4.8** (thinking) или **GPT-5.4** — лучше держат финансовую модель и аккуратный UI.  
Для быстрых правок прототипа достаточно текущей Composer.  
Дизайн-референсы смотреть на Mobbin/Gummble (YNAB, Monarch), не генерировать «с нуля в фиолетовом».
